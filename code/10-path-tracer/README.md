# 10 · 路径追踪器（C++ 零依赖 · Cornell Box · NEE）

阶段 3 验收第二张图：**Cornell Box**。对应 `docs/06`（渲染方程 → 蒙特卡洛 → 直接光采样 NEE）与 `docs/01`（蒙特卡洛积分）的完整落地。与 `code/09`（软光栅）合成阶段 3 一对：一个回答"像素怎么画"，一个回答"颜色从哪来"。

## 运行

```bash
./build.sh
./pathtracer              # 默认 480x360, 128 spp
./pathtracer 960 720 512  # 高质量(约 12s)
open out.tga              # Preview 直接打开
```

## 本例要点

| 知识点 | 位置 |
|---|---|
| **渲染方程的蒙特卡洛求解**：throughput × radiance 累积 | `trace()` |
| **NEE（下一事件估计）**：漫反射命中点显式采样面光源，含**面积 pdf → 立体角 pdf 换算**（`dω = cosθ_L·dA/d²`） | `neeDirect()` |
| **避免双重计数**：只有来自相机/镜面弹射的路径直接看到发光体，漫反射来源由 NEE 负责 | `specularBounce` 标志 |
| 余弦加权半球采样（pdf = cosθ/π，BRDF·cos/pdf 恰好约掉为 albedo） | `cosineHemisphere()` |
| Lambert / Metal(fuzz) / **Dielectric(Schlick Fresnel)** 三材质 | `scatter()` |
| 轴对齐矩形求交（墙面/面光源）+ 球求交 | `Rect::hit` / `Sphere::hit` |
| PCG32 每线程独立流 | `Rng` |
| 多线程按行取任务（atomic 行计数器） | `main()` 线程池 |
| gamma 2 输出（sqrt），无限幅 tone map——路径追踪的"诚实"呈现 | 写出循环 |
| 简易 Russian roulette（throughput 阈值终止） | `trace()` |

**开发实录踩坑**：初版全黑。逐层插桩（中心光线命中 → NEE 单测）定位到 `neeDirect` 里 `cosθ_light` 用了光法线与 `wi`（命中点→光）的点积——**符号恒 ≤0，函数永远提前返回黑**。正确的是与 `-wi`（光→命中点）点积。教训：**几何项的每一个 cos 都要想清楚"从谁指向谁"**，渲染方程的符号错误不会报错，只会安静地变黑/变亮；NEE 这种封闭形式单元最值得写单测（固定 rng 打平均值）。

另一个坑：相机基向量 `v = cross(w, u)` 得到 (0,-1,0)，图像上下颠倒——右手系里 `u×w` 才朝上；TGA 首行是图片顶部，世界 y 要翻。**"图像翻转/镜像"是渲染器新手三大必踩坑之一**（另两个：gamma、行序）。

## 观察点与练习

- 观察：球在地板上的**彩色渗色**（color bleeding，红墙把地板染暖）；镜面球里倒映着灯；玻璃球下方偏暗（NEE 阴影光线穿玻璃即判遮挡——**无焦散**，这正是 NEE 的已知盲区）。
1. 把 NEE 关掉、`specularBounce` 恒 true：同 spp 下噪点暴涨（尤其墙角）——亲手度量 NEE 的方差收益
2. `spp` 4 → 512 渐进序列看噪声收敛 1/√N
3. 玻璃球换 Lambert 白球：渗色区域变化；再换 `emit` 15→40 看曝光
4. 光源面积 ×4（0.36→0.72 边长）：软阴影变硬、方差变小——面积与方差的权衡
5. 加 BVH（docs/06 §加速结构）：球+6 面现在暴力遍历没问题，但换成 1000 球的场景就是另一个故事
6. MIS：镜面/漫反射混合材质下 NEE 与 BSDF 采样按权重合并（docs/06 §MIS，本例是它的无权重特例）
7. 补焦散：光子映射或双向方法（docs/06 §概念级，慎入）
8. 换 `halton` 低差异序列替代伪随机：同 spp 收敛更快（docs/01 §低差异序列）
