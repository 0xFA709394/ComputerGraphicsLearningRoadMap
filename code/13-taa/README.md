# 13 · TAA 时序抗锯齿（Halton 抖动 + 历史累积 + 邻域 AABB clamp）

18 章蓝图 M3 的另一件，对应 `docs/11 §TAA` 与 `docs/02` 抗锯齿谱系（SSAA/MSAA/FXAA/TAA 的第四代）。**空格键开关 TAA**：开=稳定收敛的画面；关=逐帧亚像素抖动的闪烁（摩尔纹游走）——条纹地面 + 掠射角是走样重灾区，最适合肉眼对比。

## 运行

```bash
./build.sh
./taa          # 空格: 开关对比
```

## 本例要点

| 知识点 | 位置 |
|---|---|
| **Halton(2,3) 8 点亚像素抖动**，投影矩阵左乘 NDC 平移（docs/01 低差异序列）| `halton()` / `ndcOffsetMat()` |
| **ping-pong 历史双缓冲**（rgba16Float 线性 HDR）| `history[2]` |
| **邻域包围盒 clamp**：历史 clamp 到当前 3×3 邻域 min/max，抑制拖影/鬼影 | `taaResolveFS` |
| **90% 历史 + 10% 当前**混合；首帧权重 1.0（空历史冷启动）| 同上 |
| 静态相机 → 免速度缓冲重投影；运动物体靠邻域 clamp 拒绝失效历史（卫星球演示）| 场景设计 |
| 线性 HDR 中间结果 → 输出时才 ACES+gamma（色彩纪律，docs/09）| `blitFS` |

**开发实录踩坑**：初版混合权重写死 0.1——首帧历史缓冲为空，整帧被 0.9 倍的"黑历史"污染。修复：权重经 uniform 传入（首帧 1.0，之后 0.1）。教训：**任何依赖历史状态的算法，冷启动路径是第一测试点**（引擎里叫 warmup）。

**验证方法（headless）**：同一静场从不同抖动相位各累积 16 帧，两图逐像素平均差 = **0**（时序收敛）；抖动放大 4× 后单帧差异出现（确认抖动确实进入投影链路）。交互对比请用空格键——闪烁 vs 稳定一目了然。

## 观察点与练习

- 观察：空格切换瞬间——条纹摩尔纹从"稳定细腻"变"剧烈游走"；卫星球边缘在 TAA 下平滑且无明显拖影（clamp 在工作）。
1. 混合 0.1 → 0.02 / 0.5：拖影与锐度的权衡（0.02 时卫星球拖出长尾）
2. 去掉邻域 clamp：卫星球运动方向出现"残影"——鬼影问题的亲手复现
3. 相机加平移：静态相机假设破产 → 需要速度缓冲 + 重投影（docs/11 §TAA 完整版）
4. 抖动 8 点 → 16 点 + 旋转抖动（伪随机序列质量对收敛的影响）
5. clamp 从 AABB 改 variance clipping：拖影更少（工业做法，UE 的方案）
6. 加 sharpen pass（TAA 后画面偏软，工程标配）
