# 15 · GPU 骨骼蒙皮（骨骼链 FK + 矩阵调色板 + 两骨骼 LBS）

docs/08 动画章的参考实现（此前唯一没有代码支撑的知识章）。一根 6 骨骼的锥形"触手"：CPU 每帧做骨骼链前向运动学（行波相位，尖端甩动幅度更大），GPU 顶点着色器用**矩阵调色板 + 两骨骼线性混合**（Linear Blend Skinning）变形。**空格键开关蒙皮**：直臂 vs 挥鞭。

## 运行

```bash
./build.sh
./skinning     # 空格: 开关蒙皮
```

## 本例要点

| 知识点 | 位置 |
|---|---|
| **骨骼层级 FK**：`WorldFromJoint_i = WorldFromJoint_{i-1}·T(骨长)·R(θ_i)`，行波相位让鞭状运动传播 | `buildPalette()` |
| **调色板条目** = `W_i · T(−joint_i)`：把绑定姿态顶点搬到摆后位置（docs/08 §蒙皮矩阵推导）| 同上 |
| **LBS**：`p' = (1−w)·B_i0·p + w·B_i1·p`，法线同样混合后归一化 | `skinVert` |
| 权重来源：真实资产存顶点权重属性；本例用**沿臂参数 v 现场推导**（免资产的简化，注释里说清了差异）| 同上 |
| 调色板**平铺字段**（Swift Array 引用陷阱，11 号踩坑的复用）| `Skin` 结构 |
| 锥形网格法线含 `−dr/dy` 斜率项 | `ArmMesh` |

**headless 验证**：t=0 尖端 x=430 → t=1.5 时 x=434 且整体形态弯曲（ASCII 可见弧线）；关蒙皮则任意 t 恒为 430（直臂冻结）——蒙皮数学随时间/开关正确响应。

## 观察点与练习

- 观察：空格切换——挥动的鞭子瞬间冻成直杆；基部几乎不动（幅度 0.10）、尖端大幅甩动（0.54），行波的传播清晰可见；弯曲处网格平滑过渡（两骨骼权重混合的功劳）。
1. 骨数 6 → 2 / 24：看混合带宽与平滑度
2. 把 LBS 换**双四元数**（DQS）：极端弯角下 LBS 的"糖果纸塌陷"体积损失消失（docs/08 §蒙皮的已知缺陷）
3. 行波改噪声驱动（两端固定的驻波 → 真鞭子的物理感）
4. 加第二根触手共享调色板 shader：验证"一套 PSO 多骨架"（uniform 索引实例化）
5. 蒙皮搬到 compute（GPU 计算 palette 或顶点预处理）：docs/08 §GPU skinning
6. 从 glTF 读取真实骨骼/权重（KHR_skin），替换现场推导——对照 docs/10 资产管线
