## v2 · glTF 网格输入（练习 3 落地，案例 B 第 3 周）

资产链全通：**程序化三叶结 → 写标准 glTF（knot.gltf+knot.bin，19 号同构段序）→ 手写最小读回器 → gltfToTriangles → SAH-BVH**。基准维持 358~389×（20480 三角经 61440 索引往返无损）。

**v2 踩坑实录**：
1. **手写 JSON 解析器的字符数陷阱**：`"count":` 是 **8 字符**（含两个引号与冒号），偏移写 +7 → `atof` 从冒号解析恒为 0——且独立最小文件测试时测试串不同而"通过"。教训：**格式常量提取为具名常量或直接用库（cgltf）**，手写字符偏移是最脆的写法。
2. **`find` 循环的前进量**：命中后只前进 1（而非模式长度），否则下一次 find 从值中间开始漏匹配。
3. **BVH 空网格防护**：`nodes[0]` 写入前不检查 `tris.empty()` = 段错误。防御式检查 + 明确报错。
