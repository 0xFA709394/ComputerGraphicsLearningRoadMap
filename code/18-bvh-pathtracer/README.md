docs/06 §求交/加速结构的落地，docs/27 案例 B 第 1~2 周的参考实现。在 code/10 之上新增：**Möller–Trumbore 三角形求交、AABB、SAH 构建的 BVH、程序化三叶结网格（20480 三角）**，以及暴力 vs BVH 的加速基准（验收物）。

## v2 · glTF 网格输入（练习 3 落地，案例 B 第 3 周）

资产链全通：**程序化三叶结 → 写标准 glTF（knot.gltf+knot.bin，19 号同构段序）→ 手写最小读回器 → gltfToTriangles → SAH-BVH**。基准维持 358~389×（20480 三角经 61440 索引往返无损）。

**v2 踩坑实录**：
1. **手写 JSON 解析器的字符数陷阱**：`"count":` 是 **8 字符**（含两个引号与冒号），偏移写 +7 → `atof` 从冒号解析恒为 0——且独立最小文件测试时测试串不同而"通过"。教训：**格式常量提取为具名常量或直接用库（cgltf）**，手写字符偏移是最脆的写法。
2. **`find` 循环的前进量**：命中后只前进 1（而非模式长度），否则下一次 find 从值中间开始漏匹配。
3. **BVH 空网格防护**：`nodes[0]` 写入前不检查 `tris.empty()` = 段错误。防御式检查 + 明确报错。

## v3 · BDPT 双向路径追踪 + MIS（docs/06 §MIS 完整落地）

在 v2 的 NEE 路径之外新增**双向策略**，渲染时 NEE/BDPT 各占一半样本：

- **相机链**：常规路径追踪顶点（throughput 累计）；
- **光源链**：面光源均匀采样 + 余弦方向出射，链长 1~2；
- **连接**：每对（相机前缀 t × 光源前缀 s）做 `connectVertices`——几何项 G = cosθₐ·cosθᵦ/d²，双向 Lambert BRDF，阴影测试；
- **幂次启发式 MIS**：`w = 1/(1+(s/t)²)`，两策略互补加权（s≪t 时光源策略主导，反之亦然）。

**验证**：480×360@256spp 成像正确（间接区无偏黑、直接光区无过曝——MIS 权重正确的定性证据：错误的权重会表现为特定路径族的能量翻倍/丢失）。定量方差对比（BDPT vs 纯 NEE 的同 spp 标准差）留作练习——需要固定种子多次渲染取统计。

**v3 踩坑实录**：无新坑——`std::pow`/`std::vector` 在 -O2 下正常，但注意 `connectVertices` 的自遮挡偏移（1e-4 双端）不可省，否则光源链立即自遮成全黑。

## v4 · 单向 MLT + 焦散场景（第 8~9 周落地）

**Metropolis 光传输**：状态 = 像素样本(u, v + 路径种子)。**大步长跳变 10%**（全新随机状态保证遍历性）+ **小步变异 90%**（各分量高斯微扰），Metropolis 准则 `I(new)/I(old)` 接受；预热 8k 步估计 b（平均亮度）做期望归一。

**焦散场景**（MLT 的存在理由）：玻璃球（新增 Dielectric 材质：Schlick 折/反 + 镜面链）+ 光源缩小到 0.42~0.58——普通路径追踪命中“光→玻璃折射→地面”路径的概率趋近零；MLT 靠马尔可夫链**粘在**亮路径附近持续探索。

**验证**：MLT 输出非零像素 46%、均值 19.9、焦散区峰值 97（对照：金属球直接光参考均值 90）。图像偏暗 = 64 spp 等效预算 + 教学版归一近似的边界（严格实现按接受率精确归一）。

**v4 踩坑实录**：
1. **`Hit.front` 缺失**：介质折射方向判定需要知道命中面是外是内——新增材质时要检查求交结构是否带足信息。
2. **多线程 accum 归一化必须在 join 之后**：每线程各自乘归一系数 = 后写线程覆盖前写线程的缩放（数据静默错 10 倍）。
3. **`Vec3` 无 `/double` 运算符**：以最晦涩的编译错误表现——标量除法要写成分量除。
