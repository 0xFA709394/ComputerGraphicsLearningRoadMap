# 21 · SDF 球体追踪（全片元着色器 · 零网格）

README 实战清单第 1 项「ShaderToy 复刻（ray-marching 场景）」的参考实现，对应 docs/05 §隐式表面/SDF/ray-marching。**整个场景没有一个顶点/索引缓冲**——几何、光照、阴影、AO 全部由距离函数在片元着色器里计算。

## 运行

```bash
./build.sh
./sdf
```

## 本例要点

| 知识点 | 位置 |
|---|---|
| **SDF 原语**：球/圆角盒/环/平面（docs/05） | `sdSphere/sdBox/sdTorus/sdPlane` |
| **光滑布尔**：`smin` 多项式变体，k 控制融合半径——SDF 的"抗锯齿布尔" | `smin` |
| **球体追踪**：步长=当前距离，指数收敛不穿面（对比 09 的固定步长光栅化） | `march` |
| **法线=距离场梯度**（中心差分）——不存顶点法线的代价与自由 | `calcNormal` |
| **SDF 软阴影**：朝光 march，半影 ∝ min(s/k·d)——比阴影图便宜且无 acne | `softShadow` |
| **SDF 免费 AO**：命点邻域距离采样 | `calcAO` |
| 距离雾 + 假天空反弹 + gamma | `fs` |

**headless 验证**：lit 100%、暖色盒 7.2%；ASCII 可见透视棋盘、圆角盒软阴影、右侧光滑融合体。

## 练习路线

1. 自定义域扭曲（`p.xz += sin(p.y*3)*0.1`）——SDF 的"有机形变"魔法
2. mandelbulb（分形 SDF，docs/05 §隐式表面深水区）
3. SDF 与光栅混合：SDF 场景 + 19 号 glTF 网格同屏（工业用法：UE Lumen 的远场）
4. 步进预算 96 → 48/192：质量-性能曲线（对比收敛失败的白噪点）
5. 移植回 ShaderToy（本例即其逆向——GLSL↔MSL 互译练习）
