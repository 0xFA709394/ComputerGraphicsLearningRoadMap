# 26 · 训练执行计划：26 周从 iOS 到图形学

> 把 README 主线、25 章文档、11 个示例串成**可勾选的周计划**。前提：每天 1~1.5 小时 + 周末 3~4 小时整块（合计 ≈ 12 小时/周）。进度落后不超过 2 周就不算落后——**跳过"补作业式追赶"，直接按当前周继续，用 13/19/21 章的自测清单补漏**。

## 使用规则

1. 每周有一个**验收物**（图/程序/笔记），做不出来不算完成。
2. 示例代码（code/）是**参考答案**：先自己写，卡住超过 1 小时看一眼思路（不是抄），写完再对照复盘差异。
3. 每天 15 分钟 Anki（20 章），雷打不动——这门课的知识密度靠记忆锚点撑住。
4. 每月末写一篇复盘（八、节奏建议），把这月"能跑"的代码重构成"能看"的。

## 三条铁律（踩过的人都会同意）

1. **图不对就查色彩空间**：一半的"渲染怪怪的"是 gamma/linear/sRGB 时序问题（24 章树 2）。
2. **矩阵约定写死注释**：z∈[0,1] 还是 [-1,1]、正距离还是 view.z、y 翻不翻——code/11 的踩坑 1 值得背下来。
3. **验证靠数据不靠眼神**：亮像素占比、定点探针、debug 编码颜色——本仓库每个示例的"已验证"都是这么来的，把这个习惯带进你自己的项目。
