# 19 · 白板代码题集（15 题 · 自测与面试演练）

> 图形岗手写代码题的高频全集。用法：**先不看答案默写，再对照章节核对**。每题附"考官追问"——真正区分度在追问。

---

## 题 1 · LookAt 矩阵
> 写 `lookAt(eye, target, up)`（相机看 −Z）。
参考：01 章扩展篇 C（三基向量 + 平移列 = −(基·eye)）。
**追问**：up 与 forward 平行时发生什么？（叉积为零向量 → 除零崩溃；需 fallback 世界 up）；为什么平移列是负点积？

## 题 2 · 透视投影矩阵
> 推导 GL 风格 P，再改成 Metal（z∈[0,1]，y 翻转）。
参考：01 章扩展篇 A 四步推导（相似三角形 → w=−z → 解 α/β → API 修正）。
**追问**：z_ndc 与 1/z 的关系？为什么 far/near 比值过大出 z-fighting？（非线性深度精度分布）

## 题 3 · Möller–Trumbore
> 手写光线-三角形求交，含所有分支。
参考：06 章正文代码块（det 平行剔除 / u,v 域判断 / t 区间）。
**追问**：为什么不能先算 t 后算 u,v？（可以先——考你理解自由度）；如何让它 watertight？（共享边数值一致性，PBRT 方案）

## 题 4 · 软光栅三角形
> 写 `rasterize(A,B,C, shader)`：边函数 + 重心 + z-buffer + 透视校正插值。
参考：02 章扩展篇 A（含增量求值与统一绕向技巧）。
**追问**：top-left rule 解决什么？（共享边双重计数）；把 z 比较改成 reversed-z 需要改哪几处？

## 题 5 · 直接光 GGX
> 写完整直接光 PBR：D/G/F + Lambert + 能量组合。
参考：03 章正文 §8.2 骨架 + 扩展篇 A 完整 MSL。
**追问**：`1e-4` 防什么？（NdotV→0 的镜面发散）；metallic=1 时 diffuse 为什么置零？

## 题 6 · 余弦加权半球采样
> 写采样函数并验证 pdf = cosθ/π。
参考：01 章扩展篇 E（r=√ξ₁ 的必要性 + 投影验证）。
**追问**：为什么 r 必须 √ξ？（圆盘面积微元均匀）；采样局部系如何转世界系？（TBN 乘）

## 题 7 · 蒙特卡洛积分验证
> 用 MC 数值验证 `∫₀^π sin(x) dx = 2`（均匀采样与重要性采样各一遍，报告误差-样本数曲线）。
参考：01 章 §6.2 + 06 章扩展篇 D 实验三连。
**追问**：误差随 N 如何衰减？(1/√N)；如何验证估计量无偏？（均值收敛于真值、多组样本均值无系统偏移）

## 题 8 · AABB slab 相交
> 写 ray-AABB，返回 tmin/tmax。
参考：06 章 §1.2（逐轴区间取交，注意除法负号处理分支）。
**追问**：GPU 上为什么避免分支写法？（发散；用 min/max 组合无分支版）；它在 BVH 遍历里的位置？

## 题 9 · 四元数→矩阵 + slerp
> 写 q→R（3×3）与 slerp。
参考：01 章 §4.1 矩阵公式 + 扩展篇 D（短弧处理与 0.9995 退化）。
**追问**：dot<0 不处理会怎样？（绕远弧）；为什么工程上常用 nlerp？

## 题 10 · PBD 距离约束一步
> 给两粒子 (p₁,p₂,rest,w₁,w₂)，写一次约束投影。
参考：14 章 §4.1（`s = C/wSum`，双方按 invMass 分摊）。
**追问**：迭代次数与刚度关系？（收敛而非物理刚度——XPBD 如何修复）；w=0 什么含义？（钉死/无穷质量）

## 题 11 · TAA resolve 核心
> 写重投影 + 邻域钳制 + 混合。
参考：02 章扩展篇 D。
**追问**：min/max 钳制的副作用？（过度钳制历史→细节损失）；大位移物体怎么办？（velocity 判据弃历史/提高 alpha）

## 题 12 · mip 层级计算
> 在 shader 里手写 `textureLod` 的 λ 公式。
参考：04 章 §2.2（ρ = max(‖ddx uv‖, ‖ddy uv‖)，λ=log₂ρ）。
**追问**：quad 内 ddx 如何来的？（helper lanes，02 章 §5.3）；非均匀分支里为何失效？

## 题 13 · sRGB ↔ linear
> 写双向转换（分段函数）。
参考：13 章附录 A（0.04045/12.92 阈值版，不是 pow(1/2.2)）。
**追问**：pow(2.2) 近似的误差多大？（暗部差异明显，banding 相关）；哪个方向的转换在哪个硬件单元自动发生？（OM 出口/采样入口）

## 题 14 · PCF 3×3 阴影
> 写 shadow map 采样（含 bias 与比较平均）。
参考：11 章 §1.1 + 扩展篇 A 第 3 步。
**追问**：bias 不足/过度的症状？（acne/Peter-panning）；为什么不能直接对深度图双线性后再比较？（非线性值均值无物理意义——PCF 是"比较后滤波"）

## 题 15 · 环形常量分配器
> 设计每帧 draw 的 uniform 子分配：`alloc(size, alignment) -> offset`，环形复用，防在飞帧覆写。
参考：18 章 M0 + 10 章 §5.4。
```cpp
struct RingAllocator {
    std::vector<uint8_t> buf; size_t head = 0, capacity;
    // 帧结束不回收; 每帧开始检查最老在飞帧的 fence:
    // head 只在 [head, head + frameMax) 内回绕, 三缓冲各持有区间
    size_t alloc(size_t size, size_t align, uint64_t frameIndex);
};
```
**追问**：为什么必须 N 倍缓冲？（CPU 写第 i+2 帧时 GPU 可能还在读 i 帧）；alignment 的依据？（256B—— Metal uniform 缓冲性能约定）。
