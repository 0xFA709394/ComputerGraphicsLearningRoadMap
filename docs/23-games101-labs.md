# 23 · GAMES101 作业通关指南

> 路线第一里程碑（阶段 2）的护航文档：7 次作业的目标、知识映射、常见 bug 与验收标准。原则：**框架代码先读懂再写；不看现成答案 repo**——作业的价值在踩坑，不在绿灯。

## 作业 0：环境搭建

- macOS：clang + CMake + Eigen（`brew install eigen cmake`）；VS Code/CLion 任一。
- 提供框架为 CMake 工程，`mkdir build && cmake .. && make` 跑通即过。
- **纪律**：从作业 0 起就用 git 管理，每次提交对应一个功能点——18 章的习惯从这里养成。

## 作业 1：旋转与投影（01 章主场）

**任务**：`get_model_matrix`（绕任意轴旋转→Rodrigues）、`get_view_matrix`（lookAt 已给）、`get_projection_matrix`（fov/aspect/n/f → 透视）。

**知识映射**：01 章扩展篇 A 的推导照抄即可——**但必须先自己推一遍再对答案**。

**常见 bug**：
- fov 单位是度还是弧度（框架是度，记得 `*pi/180`）；
- z 方向与平移项符号（框架约定右手系、相机看 +Z 的镜像世界——按框架推导，别硬套 OpenGL 记忆）；
- 图像 y 翻转（光栅化框架的 rasterizer 坐标约定）。

**验收**：三角形随按键旋转平滑、透视近大远小、与参考 GIF 逐帧一致。

## 作业 2：三角形光栅化（02 章主场）

**任务**：`rasterize_triangle`：包围盒遍历 + 重心坐标 inside 判断 + 深度插值 + z-buffer。

**知识映射**：02 章扩展篇 A 的软光栅代码（本作业不需透视校正——框架顶点已在屏幕空间，但**提高项要能答"为什么"**）。

**常见 bug**：
- 采样点用像素中心（+0.5, +0.5）而非整点；
- 重心坐标叉积符号（三边同号判定）；
- 深度初始化为正无穷且比较方向写反。

**验收**：三色三角形边缘无缺口；按 1/2/3 键切换三个三角形无异常遮挡。

## 作业 3：深度缓冲与纹理（02/04 章主场）

**任务**：z-buffer 替换画家算法；纹理采样（ nearest/bilinear 手写）；bump/displacement（法线扰动）。

**知识映射**：双线性插值（04 章 §2.1 两步 lerp）；法线扰动公式 `n' = normalize(n + dpdu·u'·scale + dpdv·v'·scale)`——**d 是"高度对参数的导数"方向扰动，不是加高度**。

**常见 bug**：
- 纹理坐标越界 clamp（框架 `wrap` 语义）；
- 双线性用了两次最近邻（应先 x 后 y 的两次 lerp）；
- displacement 幅度把网格撕破（法线方向/步长理解错）。

**验收**：bump 开关下光照方向正确偏转；displacement 下轮廓真实起伏（不只是颜色变化）。

## 作业 4：贝塞尔曲线（05 章主场）

**任务**：de Casteljau 递推采样曲线（给控制点与参数 t）。

**知识映射**：05 章扩展篇 A 的 10 行实现。**提高项（反走样）**：屏幕空间曲线按导数自适应采样步长，或分层抖动。

**验收**：曲线随控制点拖动实时更新；与 ppt 的层次递推图能对上。

## 作业 5：Whitted 光线追踪（06 章主场·第一个大作业）

**任务**：`generateRay`（从相机生成主光线）、球面/三角形求交、递归反射/折射（Schlick 菲涅尔权重分光）。

**知识映射**：06 章 §1.2 求交公式 + §2 whitted 递归。**提高项（微表面+蒙特卡洛）**：06 章扩展篇 A 的路径雏形。

**常见 bug**：
- 折射方向公式（Snell 解二次时的符号选择）；
- TIR（全内反射）分支漏掉——玻璃球黑斑；
- 递归深度与 ε 自遮挡（t_min 设 1e-3）；
- Schlick 的 cosθ 在折射侧要用**转换后的角**。

**验收**：三球场景与参考图一致：金属球反射、玻璃球内壁倒影、地面投影正确。

## 作业 6：BVH 加速（05/06 章主场）

**任务**：BVH 构建（中位数划分）+ 遍历求交。

**知识映射**：06 章扩展篇 B（本作业中位数即可，**提高项 SAH**）。

**常见 bug**：
- 遍历未先近后远（正确性没问题但性能差）；
- 叶子阈值过大/过小的性能倒挂；
- 递归改栈时的节点入栈顺序。

**验收**：与暴力遍历逐像素一致（正确性）+ 渲染时间下降一个量级（性能）——**两个都要测**。

## 作业 7：路径追踪（06 章主场·毕业作业）

**任务**：`PathTrace`：BRDF 采样（漫反射余弦采样）、RR 终止、直接光（提高项 NEE+MIS）。

**知识映射**：06 章扩展篇 A 全文——这份作业做完，扩展篇的每一行你都有肌肉记忆了。

**常见 bug**：
- throughput 忘乘 `f·cosθ/pdf`；
- pdf 用错（余弦采样 pdf=cosθ/π，不是均匀 1/2π）；
- RR 概率没除回去（有偏）；
- 自发光与 NEE 双计（MIS 权重）。

**验收**：Cornell Box 收敛图无偏色；spp 加倍噪声按 1/√N 下降（自己截 4 档对比图，06 章实验三连）。
