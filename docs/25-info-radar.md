# 25 · 信息源雷达（持续跟踪策略）

> 入门靠课程，深入靠信息流。本文给出一份"≤10 个信源"的极简雷达——信息源越多越焦虑，越少越有效。每季度审视一次，淘汰不读的。

---

## 1. 核心信源（必订，共 7 个）

| 信源 | 类型 | 频率 | 为什么 |
|---|---|---|---|
| **Graphics Programming Weekly**（Jendrik Illner）| 周报 | 每周 | 图形圈唯一的优质聚合器：论文/博客/工具一站巡览 |
| **Advances in Real-Time Rendering**（SIGGRAPH Course）| 课程 | 每年 | 游戏渲染年度论文集：引擎厂商第一手技术（YouTube 全免费）|
| **GDC Vault / GDC Channel**| 演讲 | 常年 | 工程实践浓度最高； graphics track 按引擎检索 |
| **ACM SIGGRAPH（含 Asia）**| 会议 | 每年 | 学术前沿；`Ke-Sen Huang` 的论文列表页是年度总目录 |
| **GAMES Webinar / GAMES 系列课程动态**| 社区 | 不定期 | 中文圈学术报告与课程更新（B 站/官网）|
| **Apple Developer：WWDC Metal Track**| 官方 | 每年 + 季度更新 | Metal 3/EDR/MetalFX 的一手资料；Release notes 必读 |
| **Filament / wgpu / UE5 官方博客**| 工程 | 低频 | 工业级实现的一手变更说明 |

## 2. 经典教程站（查阅型，不订阅）

- **scratchapixel.com**——按主题查概念（光线/纹理/光照全覆盖）
- **The Book of Shaders**——片元shader 交互式教学（17 章前置）
- **learnopengl-cn / learnopengl.com**——管线概念权威教程（16 章对照实现）
- **pbr-book.org（PBRT）**——离线渲染字典（06 章）

## 3. 论文阅读入口

- 年度 SIGGRAPH 论文列表（Ke-Sen Huang 页面）→ 标题海选 → 12 章三遍法精读
- 谷歌学术订阅 3~5 个关键词作者（`Real-Time Rendering`、`ray tracing`、`neural rendering`）
- 每年只精读 10~15 篇 + 泛读 30 篇——12 章论文清单是起点

## 4. 中文圈精选

- GAMES101/104 课程评论区与作业讨论（B 站/知乎）
- 知乎图形学话题下的高赞长文（按作者收藏，不按话题刷）
- 各引擎厂商技术公众号转载（注意时效与二手转述失真，回溯原文）

## 5. 例行动作（防"收藏=学会"综合征）

```
每周 30 分钟:  Graphics Weekly 扫标题 → 挑 ≤1 篇精读 → 一句话笔记
每月 1 小时:   本月笔记归档进对应章节"扩展线索"区
每季度:        审视信源——没读的直接退订
每年 6~8 月:   SIGGRAPH 年度论文海选(2 小时)
```

## 6. 判断信源质量的三个信号

1. 给出**数据与对比图**（帧时间/counters/收敛曲线），而不是只给结论；
2. 说明**失败与限制**，而不是只展示成功效果；
3. 有**可复现细节**（伪代码/参数/硬件环境）。
三条全无的技术转载 → 直接关掉。

## 7. 与全书的联动

- 新概念 → 判断归属章节 → 补进该章"扩展线索"；
- 新工具 → 先看是否解决你**当前项目**的具体问题，否则只记名字不投入时间；
- 新热点（如 3DGS 当年）→ 用 12 章方向 D 判断法：离你的作品集目标近吗？
**信源为项目服务，项目为作品集服务**——这个顺序不倒置，信息焦虑自然消失。
