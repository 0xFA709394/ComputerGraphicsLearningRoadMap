# 24 · 故障诊断决策树（按症状索引）

> 渲染调试手册：十大症状的排查决策树，按概率排序分支，节点标注对应章节。用法：出现症状 → 从树根走到底 → 修复后把结论写进自己的 bug 笔记（半年后这本笔记比任何文档都值钱）。

---

## 树 1 · 画面全黑/全空

```
有清屏色吗？
├─ 无(纯黑) → drawable 没呈现/层配置错 → 15/16 章
└─ 有清屏色, 无几何 →
   ├─ draw call 真发出去了吗? (GPU Debugger 帧捕获逐 pass 看) → 10
   ├─ 剔除把所有实例干掉了? (剔除计数 readback) → 11
   ├─ 深度初始化/比较方向反了? (reversed-z 常见) → 01/02
   ├─ 顶点绕向×cullMode? (先全部关 cull 试) → 02
   └─ uniform MVP 是不是单位阵/投影 w 反号 → 01
```

## 树 2 · 模型消失/部分消失

```
├─ 整体消失 → 树 1 全套
├─ 随相机角度消失 → 背面剔除方向(绕向/CW-CCW) → 02
├─ 只有某些三角形消失 → 退化三角形/索引越界/winding 混乱 → 05
├─ 远处消失 → 远裁面太小 → 01
└─ 移动后消失(大世界) → fp32 精度抖动 → 相机相对渲染 → 01
```

## 树 3 · 画面发灰/发暗/过曝

```
├─ 整体发灰 → albedo 没标 sRGB(被当线性) → 04/09
├─ 整体过亮/对比低 → albedo 标了 sRGB 但双解码(格式+手动) → 09
├─ 亮部死白 → 中间 RT 是 LDR(截断) → RGBA16F → 09
├─ 暗部死黑 → tone curve 缺失/曝光错 → 09
├─ 混合边缘灰边 → 非预乘纹理进 premultiplied 管线 → 02/15
└─ tone map 后"脏橙" → ACES 输入没在线性空间 → 09
```

## 树 4 · 闪烁/时序噪点

```
├─ 高光点闪烁 → 着色信号高频(小亮面/镜面) → TAA/加大 BRDF 采样 → 02/03
├─ 边缘闪烁走样 → 几何高频 → MSAA/TAA → 02
├─ 阴影边缘闪 → CSM 未做 texel snapping → 11
├─ 随机白斑(firefly) → 路径追踪低概率样本 → clamp/分层 → 06
├─ 贴图远处闪 → mip 未生成/各向异性未开 → 04
└─ 间歇性撕裂 → present 与 vsync/ProMotion 节奏 → 07/15
```

## 树 5 · 帧率低（先归因再动手）

```
Metal System Trace: CPU 编码与 GPU 执行谁满?
├─ CPU 满 →
│   ├─ draw call 数量级 >几百 → 合批/实例化/indirect → 07
│   ├─ 验证层没关(Release?) → 10
│   ├─ 每帧创建资源/编译 → 池化+预热 → 10
│   └─ 单线程编码 → 并行 command buffer → 07
└─ GPU 满 → counters 三问 →
    ├─ 带宽高 → RT 格式/load-store/pass 数/纹理采样数 → 07
    ├─ ALU 高 → half 化/LUT/减少每像素循环 → 07
    ├─ 顶点/光栅化前端高 → 三角形太小(LOD)/顶点带宽 → 07
    └─ 占用率低导致延迟暴露 → 寄存器/线程组调整 → 07
```

## 树 6 · 偶发掉帧（1/100~1/1000 帧）

```
├─ 与内存增长相关? → 泄漏/压缩纹理重复上传 → Instruments Leaks
├─ 与场景切换相关? → 流式加载尖峰 → 上传预算化 → 21
├─ 与后台任务相关? → 网络/磁盘抢占 → QoS 分级
├─ 首次出现某物体? → PSO 变体即时编译 → 预热 → 10
├─ 热状态升高后? → 降频 → DRS/MetalFX 兜底 → 07/09
└─ 无规律 → 长时间 trace 分桶统计(不看单帧) → 07
```

## 树 7 · GPU 崩溃/断言

```
├─ validation 报 feedback loop → 同一 RT 同 pass 又读又写 → 02
├─ 越界纹理采样 → UV 越界/mip 缺失/数组越界 → 04
├─ 除零/NaN 传染 → NdotV 无 clamp; 检查"一帧全 NaN"扩散 → 03
├─ buffer 被释放 → 生命周期/在飞帧引用 → 10
└─ 线程组越界 → dispatch 尺寸未对齐 threads-per-threadgroup → 07
```

## 树 8 · 阴影三病

```
├─ acne(自阴影条纹) → bias 不足 → slope-scaled/normal offset → 11
├─ Peter-panning(阴影脱体) → bias 过大/正面剔除深度 → 回调 bias → 11
├─ 边缘太硬/太假 → 面光源尺寸/PCSS 半影估计 → 11
└─ 相机移动时闪 → texel snapping 未做 → 11
```

## 树 9 · 贴图异常

```
├─ 位置错乱 → UV 通道/纹理旋转元数据(mip 上传时) → 04
├─ 颜色错通道 → 通道打包约定(RMA: R=metallic?) → 03/04
├─ 远处闪 → mip/各向异性 → 04
├─ 图集渗色 → padding 不足/未预乘 → 04/17
└─ 烘焙光照图错位 → UV2 重叠/矩阵不一致 → 05/11
```

## 树 10 · 动画/蒙皮异常

```
├─ 模型炸开 → 权重未归一化/索引越界 → 08
├─ 拖尾/抖动 → prevTransform 未更新(TAA velocity) → 08/11
├─ 关节凹陷 → LBS 糖果纸 → twist 骨骼/DQS → 08
└─ 动画"漂移" → 根运动双算/时间轴双采样 → 08
```

---

## 使用纪律

1. 每棵树走完仍无解 → **最小复现工程**（二分删除 pass/物体/shader）——所有复杂 bug 的终极手段。
2. 修复后在 `BUGLOG.md` 记一行：症状/根因/章节/修复 PR——你的个人树 11 就是这么长出来的。
3. 帧捕获是第一反射：**"不看捕获就猜"是渲染调试第一反模式**。
