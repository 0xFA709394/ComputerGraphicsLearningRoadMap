# 14 · 物理模拟入门

> 渲染管线的"另一半逼真度"。定位：游戏引擎方向必修、布料/AR 交互常用。目标不是写 Havok，而是掌握**积分器 / 碰撞 / 约束**三大件，能独立做粒子-布料-简单刚体。

---

## 1. 数值积分（一切的起点）

### 1.1 积分器族谱
| 积分器 | 公式 | 特点 |
|---|---|---|
| 显式欧拉 | `x += v·dt; v += a·dt` | 简单，能量发散（弹簧越弹越大）|
| **半隐式（辛）欧拉** | `v += a·dt; x += v·dt` | 顺序换了，稳定性大增——游戏标准 |
| Verlet | `x_new = 2x − x_old + a·dt²` | 无速度状态，约束友好（布料）|
| Leapfrog/RK4 | — | 高精度，离线/轨道用 |

### 1.2 稳定性工程
- 刚度大的力（弹簧）逼显式积分用极小步长 → **用位置约束替代硬弹簧**（PBD 的动机）。
- **固定步长 + 累加器 + 渲染插值**：物理恒定 60/120Hz，渲染任意帧率在两个物理快照间插值——抖动唯一正解。
- **CCD（连续碰撞检测）**：快速物体按扫掠形状（swept sphere）测试，防穿透。
- substepping：一帧内多次小步（4×dt/4 常胜过 1×dt）。

## 2. 粒子物理（已在 07 章 kernel 的理论面）

- 力族：重力/风（速度相关阻力 `F = −k·v`，帧率无关写法 `v *= exp(−drag·dt)`）/噪声湍流/吸引子。
- 球-SDF 碰撞反弹：`n = ∇sdf(p)`；`v' = reflect(v, n)·restitution`。
- 互作用力（吸引/排斥）是 O(n²) → 空间哈希邻居查找（03/05 章结构复用）。

## 3. 刚体动力学

### 3.1 状态与方程
- 状态：位置 x、姿态 q（四元数）、线速度 v、角速度 ω、质量 m、**惯性张量**。
- 惯性张量：物体空间 `I_body`（由几何积分预计算）；世界空间每帧 `I = R·I_body·Rᵀ`。
- 动力学方程：
```
v̇ = F/m
ω̇ = I⁻¹·(τ − ω × (I·ω))      // 陀螺项 ω×(Iω)：旋转体角动量守恒的表现
```
- 冲量（impulse）形式：`v += J/m`，`ω += I⁻¹·(r × J)`——碰撞/约束统一语言。

### 3.2 碰撞检测两级
- **宽相**（找候选对）：AABB 树 / sweep-and-prune（轴排序找重叠）/ 空间哈希。目标 O(n)~O(n log n)。
- **窄相**（精确几何）：
  - **SAT**（分离轴）：凸多面体经典，盒-盒最快；
  - **GJK**：任意凸形状距离（支撑点 + Minkowski 差单纯形迭代）；
  - **EPA**：GJK 的扩展，给穿透深度与法线。
- 流形（manifold）：一个碰撞对产出 1~4 个接触点（保稳定堆叠）。

### 3.3 碰撞响应与约束
- 法向冲量（含恢复系数 e、相对速度投影）：
```
j_n = −(1+e)·(v_rel·n) / (1/m₁ + 1/m₂ + (r₁×n)·I₁⁻¹(r₁×n) + ...)
```
- 摩擦：切向冲量钳制在库仑锥 `|j_t| ≤ μ·j_n`。
- **顺序脉冲（Sequential Impulse，Box2D 作者 Erin Catto）**：迭代解接触约束（投影/冲量交替），收敛即稳定堆叠；本质是 Gauss-Seidel 解互补问题。
- 休眠（sleep）+ 岛（island，连通刚体分组一起休眠）——大规模场景的节电关键。

## 4. 布料与 PBD（Position Based Dynamics，实时布料标准）

### 4.1 PBD 核心循环
```cpp
// 粒子: pos, prevPos, invMass
void step(float dt) {
    for (p : particles) { p.prev = p.pos; p.vel += gravity*dt; p.pos += p.vel*dt; }
    for (iter = 0; iter < 8; ++iter) {                    // 迭代次数=刚度
        for (c : constraints) {                           // 距离约束
            Vec3 d = q.j - q.i; float len = length(d);
            float C = len - c.rest;
            float wSum = p.i.invMass + p.j.invMass;
            float s = C / wSum;                           // 刚度 1
            p.i.pos += d/len * (s * p.i.invMass);
            p.j.pos -= d/len * (s * p.j.invMass);
        }
        for (p : particles) collideWithSDF(p);            // 碰撞投影
    }
    for (p : particles) p.vel = (p.pos - p.prev) / dt;    // 速度从位置导出
}
```
直觉：**先自由运动，再逐约束"掰回正确位置"**——回避了力空间积分的刚性问题，天然稳定，游戏/VR 衣服的主流。

### 4.2 约束家族与进阶
- 结构（横竖）/剪切（对角）/弯曲（隔点）三类布料约束。
- **XPBD**：PBD 的物理正确版——用柔度 α 参数化（λ 乘子累积，`α̃ = α/dt²`），约束求解与迭代次数解耦，刚度有真实单位。新项目直接用 XPBD。
- 自碰撞：布料粒子-三角对空间哈希；风：`F = n·(n·v_rel)·k`（法向面积受力）。
- 角色联动：布料粒子和蒙皮顶点钉合（max distance 约束），骨骼动画驱动。

## 5. 软体/流体概念地图（选学）

- **形状匹配（Shape Matching）**：软体目标形状的最优刚体变换回拉——快速稳定（果冻类交互首选）。
- **FEM**：有限元，形变物理正确（手术仿真/影视），游戏极少全量使用。
- **SPH**：光滑粒子流体——核函数加权密度/压力/粘性三步；邻居查找贵。
- **PBF（Position Based Fluids）**：密度约束的 PBD 化（`C = ρ/ρ₀ − 1`）——实时水体主流，compute 友好。
- **网格法（Eulerian）**：stable fluids（半拉格朗日平流 + 压力投影）——烟雾/火焰离线级质感；实时用小网格 + 上采样。
- 移动端预算直觉：粒子 5k~50k（空间哈希 + 每邻居 ~32），一个完整 PBF 水体在 A15 级设备约 2~4ms。

## 6. 物理与渲染的接口

- **变形网格回传**：compute 物理 pass 写顶点 buffer → fence → 渲染读（ping-pong 双 buffer 防 hazard，10 章机制）。
- **Ragdoll 双向**：动画驱动物理（kinematic）↔ 物理接管骨骼（dynamic）+ 混合系数过渡（08 章）。
- **时钟解耦**：物理固定步、渲染可变步；网络对战加预测/回滚（概念）。
- **AR 想定**：ARKit 平面/网格重建 → 物理世界的静态碰撞体；虚拟物体与真实桌面交互是 AR 的"杀手级说服力"来源。
